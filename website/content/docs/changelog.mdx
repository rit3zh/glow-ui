Generated from the repository's commits — releases are tag boundaries, and
anything after the newest tag is unreleased. Release plumbing and duplicate
subjects are filtered out; everything else is here.

Copied components never update themselves. A release changes the registry, not
your project: to take one, run `npx reacticx add <component> --overwrite`, and
expect to reapply any local edits. `npx reacticx diff` shows what those are.
